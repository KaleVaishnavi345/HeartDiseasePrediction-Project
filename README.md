# ❤️ Heart Disease Prediction System

A **Machine Learning based Flask web application** that predicts the probability of heart disease using patient medical parameters.

This project combines **data preprocessing, exploratory data analysis, statistical testing, machine learning model comparison, and Flask deployment** into a complete end-to-end healthcare prediction system.

---

## 🚀 Features

- 🔐 User Registration & Login System
- 📊 Dashboard for patient interaction
- 🧠 Machine Learning prediction model
- 📈 EDA and visualization notebooks
- 📉 Correlation heatmap and data insights
- ⚡ Real-time heart disease risk prediction
- 🎨 Attractive HTML/CSS frontend templates
- 📦 Pre-trained `.pkl` models included
- 📝 Form validation using JavaScript
- 🌐 Flask backend routing system
